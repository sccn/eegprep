Phase 4: Time-Frequency Internals And Legacy Entry Points

Implemented In This Branch

  • Added standalone time-frequency helpers: timefreq, dftfilt, dftfilt2, dftfilt3, newtimefitc, newtimefbaseln, newtimeftrialbaseln, newtimefpowerunit, bootstat, and correct_mc.
  • Refactored newtimef onto the compute-only timefreq path and added baseline normalization, trial baseline, supplied bootstrap limits, seeded EEGPrep bootstrap significance outputs, p-value/significance masks, and curve plotting.
  • Expanded newcrossf with phasecoher2, amplitude-correlation mode, subitc, shuffle, supplied rboot, seeded bootstrap thresholds, p-values, significance masks, and curve plotting.
  • Added legacy compatibility entry points timef, crossf, pop_timef, and pop_crossf; the legacy pop wrappers return replayable same-name Python history commands while sharing the newer standalone implementations.
  • Enabled implemented pop_newtimef dialog controls for bootstrap alpha, FDR correction, and curve plotting. The tf cycle calc button remains disabled until that separate GUI workflow is ported.
  • Updated help resources, Sphinx API entries, package exports, and the Phase 1 parity matrix.

Deviations And Follow-Ups

  • bootstat accepts Python callables instead of MATLAB formula strings. This avoids runtime string evaluation and is sufficient for EEGPrep's implemented significance paths.
  • Seeded bootstrap behavior is deterministic in EEGPrep, but it is not intended to be bit-identical to MATLAB's random stream. Deterministic MATLAB parity tests cover dftfilt3, FFT timefreq, and newtimefbaseln.
  • correct_mc is implemented as a standalone Pearson-neighbor estimator. Exact EEGLAB random-symbol distribution fitting remains a Phase 7 follow-up with rsfit, correctfit, and related helpers.
  • timewarp and angtimewarp remain Phase 7 follow-ups. Consequently, pop_newtimef still fails clearly for timewarp, timewarpms, and timewarpidx.
  • PAC helpers (pac, pac_cont) are real analysis functions but are not needed by the current newtimef/newcrossf stack; they remain explicit Phase 7 follow-ups rather than stale skips.
