Phase 5b component-measure contract

Phase 5c does not precompute ERP, spectrum, ERSP, or ITC component measures. After merging Phase 5b, it reads the cached component measures that pop_precomp(..., "components") stores on the parent STUDY["cluster"][0] entry. 

{
  "name": "ParentCluster",
  "sets": [1, 2],
  "comps": [1, 2, 3],
  "measureinfo": {
    "kind": "components",
    "datasets": [1, 2],
    "components": [1, 2, 3],
    "computed": ["erp", "spec"]
  },
  "erpdata": [[[...]]],   // datasets x components x times
  "erptimes": [...],
  "specdata": [[[...]]],  // datasets x components x freqs
  "specfreqs": [...]
}

Dataset and component identifiers in measureinfo, sets, and comps are 1-based STUDY-facing values. Phase 5c expands the Phase 5b parent-cluster dataset/component axes into EEGLAB-style row-aligned sets/comps before storing STUDY["etc"]["preclust"]["preclustcomps"].

Design decisions

  • Scalp-map preclustering remains available without cached measures by reading EEG.icawinv. ERP, spectrum, ERSP, and ITC preclustering now reads the landed Phase 5b parent-cluster cache.
  • K-means uses scikit-learn with an explicit random_state. EEGLAB defaults to MATLAB kmeans with replicates; deterministic seeding is required for reviewable Python tests.
  • Unsupported EEGLAB clustering branches, including neural networks, affinity propagation, and optimal k-means, raise clear NotImplementedError messages.
  • The Phase 5c cluster plot hook intentionally plots cluster membership summaries. Full component ERP/spectrum/ERSP/ITC visualization remains coordinated with Phase 5b plotting outputs.
  • Claude Code review follow-up tightened parity and API behavior: invalid pop_clust(clus_num < 2) and non-positive outlier thresholds now raise, outlier detection uses Euclidean distance standard deviations, std_createclust numbers Cls and outlier clusters independently, and GUI pop_clustedit falls back when the threshold field is blank for non-rejection actions.
  • std_moveoutlier now stores an EEGPrep-owned outlier_parent_cluster back-reference and std_renameclust keeps outlier cluster names paired with the renamed source cluster. EEGLAB's std_renameclust.m performs the same visible outlier-name update.
  • std_mergeclust intentionally keeps the EEGLAB std_mergeclust.m hierarchy where the merged cluster lists the merged source clusters as parents and the source clusters list the merge as a child. A Claude review note suggested reparenting the merge to the shared upstream parent, but the local EEGLAB sources do not support that change.
  • Phase completion audit follow-up made GUI submit paths tolerate blank optional numeric fields for clustering, kept outlier cluster preclustdata empty until components are moved into it, and added bare eegprep-console coverage for pop_preclust, pop_clustedit(action="rename"), and pop_clustedit(action="plot").
  • The pop_preclust and pop_clustedit dialog specs now mirror the local EEGLAB source row geometry and geomvert values. The follow-up added the missing in-dialog double-dipping Help button, ERP low-pass field, ERSP/ITC frequency-range fields, scalp-map mode popup, clustedit design/list/button matrix, and source-style cluster editing buttons.

Open risks

  • The Phase 5b parent cluster stores datasets and components as separate axes for cached measures, while EEGLAB clustering stores row-aligned sets/comps. Phase 5c expands the parent cluster at preclustering time; integration tests cover this path.
  • MATLAB parity for exact k-means labels is sensitive to implementation differences. Deterministic parity should compare data structures and component coverage unless MATLAB and sklearn seeds are explicitly aligned.
  • GUI visual parity captures have been generated and attached to PR #92 as GitHub user attachments at https://github.com/sccn/eegprep/pull/92#issuecomment-4583627220. The local artifacts remain uncommitted under .visual-parity/.
