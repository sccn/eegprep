EEGLAB admin and GUI test ports

The only upstream test source used was sccn/eeglab_tests at ff605546f3f70868916fb8d49c007472b3257b50, paired with EEGLAB 8ac485f654d6bbb1a6acb8dc9ef3f2eaf3d409ba.

Design decisions

  • Tests exercise Python-native state and tagged dialog specifications; they do not reproduce MATLAB globals, base-workspace evaluation, or handle arrays.
  • Commented interactive MATLAB scripts were translated only where EEGPrep has an observable corresponding contract.
  • Scalar listdlg2 text is one item, matching MATLAB char-array behavior instead of Python's generic character iteration.
  • finputcheck keeps EEGLAB's returned-error-string contract while using an explicit return_unrecognized flag for MATLAB's optional second output.
  • inputdlg2 is represented as a tagged DialogSpec, keeping it testable without user interaction.

Parity defects fixed

  • eeg_retrieve(ALLEEG, 0) now returns an empty EEG and current index zero.
  • Commands applied to more than one EEG receive EEGLAB's multi-dataset history prefix.
  • listdlg2 now applies initial selection after inserting each Qt item and treats every non-multiple mode as single selection.

Compatibility helpers added

  • finputcheck validates legacy key/value rules, including defaults, multiple accepted types, unknown-argument handling, and the six current regression fixtures.
  • inputdlg2 and errordlg2 expose non-blocking builders used by GUI tests and capture tooling.
  • eeg_readoptions parses option scripts as data without executing MATLAB code.
  • getkeyval reads named and positional values from command-history strings without evaluating them.
  • gethelpvar extracts documented input/output variables from MATLAB help headers.
  • vararg2str serializes command arguments without evaluating user values.

Deliberate boundaries

MATLAB-only helpers and absent EEGPrep APIs are not represented by passing placeholder tests. The handoff identifies these cases so they can be tracked as missing functionality or reviewed exclusions.
