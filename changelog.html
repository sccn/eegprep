Changelog#

Notable changes to EEGPrep, newest first. Full release notes and downloads are on the GitHub Releases page.

Unreleased#

  • eeg_checkset turns a missing or empty etc into {} and leaves eeglabvers unset. A .set file written with an empty etc reloads as a dictionary, so clean_flatlines, clean_drifts, and clean_windows can store their results (#533).

  • pop_load_frombids stores a missing channel coordinate as an empty array, including a channel with no row in electrodes.tsv. Saving and reloading that dataset keeps the empty coordinates (#538).

  • eeg_getdatact computes component activity when icaact is missing, empty, or None (#506).

  • gauss with one frame returns exp(-sds**2), the single sample at -sds (#507).

  • pop_chansel reads selection text with the shared tokenizer. An empty quoted token is an empty label, and a brace-wrapped list uses the labels inside the braces (#508).

  • Import dialogs expose data shape, sampling, metadata, channel selection, ranges, event fields, units, alignment, and epoch options. Cancel preserves the dataset and history; accepted imports update the GUI and console together (F10/F19/F21/F22). CNT and EGI Simple Binary imports use their native readers; BrainVision import returns float32 samples (F23).

  • ASCII imports transpose samples-by-channels input, use float32 samples, keep channel locations and the dataset name empty unless supplied, and record the effective sampling rate. Epoch reshaping keeps consecutive samples together (F21).

  • Event import rejects capitalized reserved fields with correction advice. History accepts NumPy arrays of field names and preserves NaN options. Epoch-file import requires explicit column names and header-line counts (F19/F22). Channel-event extraction retains both types when falling and rising edges coincide (F20).

  • Presentation import offers type, latency, and duration column selection and records the choices for replay. ERPLAB import maps event lists and bin definitions onto existing events, with safe cancellation (F10/F31). CNT history retains the selected start and duration; ASCII history can replay imported channel metadata (F10/F21/F23).

  • MFF import selects the recording folder, and the MNE extra installs the XML parser required by its MFF reader (F18). Missing XML support uses the shared optional-dependency error with the extra’s installation command.

  • Neuroscan .EEG import uses the native epoch reader and retains sweep events, channel calibration, and rejected sweeps (F119), matching EEGLAB loadeeg/pop_loadeeg (accepttype='all'). Generic File-IO also recognizes EGI Simple Binary .raw files (F23). Files ending in .eeg or .EEG use BrainVision when a sibling .vhdr or .ahdr exists, including channel/sample selections and time-range imports. BrainVision time ranges use the same native reader and channel layout as full imports; blockrange converts seconds to samples at the header’s sampling rate without requiring MNE.

  • MATLAB v7.3 datasets preserve complete labels, nested references, empty events, and channel-major data even when dimensions coincide (F15, #497).

  • Dataset and BrainVision readers require bare companion filenames in header references, rejecting directories, traversal, and Windows drives (#561). Adjacent symlinks into DataLad/git-annex storage remain supported. Invalid datasets and missing sample files give recovery instructions (F34). HDF5 field-decoding errors retain their specific exception rather than being reported as invalid MAT files.

  • Save as preserves the two-file layout of loaded datasets and appends .set to extensionless names; savemode="onefile" explicitly embeds samples (F26).

  • Long preference-file paths no longer push Preferences controls offscreen; the full path is available in the option-file tooltip (F89, #556).

  • Console startup tolerates missing or closed logging streams and restores active handlers after the console exits (#556).

  • Copying rejection marks between data and ICA fields does not require an ICA decomposition. Component processing and plots retain their ICA preconditions (F64/F81, #556).

  • Saved preferences load in the interactive launchers. Imports and window or workspace constructors preserve in-process options, including when opening another GUI from a running console (F89, #556).

  • Console history replay expands MATLAB colon ranges, including stepped ranges, and accepts the three-output dataset commands stored for EEGLAB. Stored history remains unchanged (Stream 2 handover and F27/F49/F94, #556).

  • Component actions check for ICA before opening dialogs. Warnings identify the failing operation and preserve source errors; ICA and empty-result preconditions provide recovery guidance at the failure site. Help renders Markdown, updates are checked in-app, and File > Quit asks before discarding unsaved datasets (F47/F64/F81/F96/F97 and Quit audit, #556).

  • Preferences exposes memory/storage and advanced options, saves GUI choices to ~/.eegprep/options.json, restores them on launch, and updates menu visibility immediately. Unsupported global preferences are disabled and documented; native-dialog choices stay out of MATLAB history. Clear retains the dataset-number confirmation dialog supplied by the data-safety fixes (F29/F89, #556).

  • Dataset processing warns before overwriting multiple selections, rejects empty results, and opens Dataset info after merging. Session scripts and copy/select/ store commands use runnable EEGLAB forms and concrete indices; saved file history separates filename and filepath (F27/F38/F42/F49/F90/F94, #556).

  • Main-window menus retain their Qt objects across dataset refreshes and nested dialogs, including failed imports (F54/F121/F30, #556).

  • The main window shows channel-reference consensus, consistent epoch-time precision, total dataset memory, and mixed ICA status. Single-dataset selection and empty-result recovery keep the Datasets menu usable; component scrolling and ICLabel menus follow EEGLAB availability (F1/F95/F2/F3/F4/F5/F38/F93, #556).

  • Channel locations: enable Read, Look up, Plot 2-D/3-D, head-center optimization, rotation, transforms, coordinate conversions, head radius, type/reference editing, insertion/deletion, and both Save actions. Navigation and action history preserve edits in order, and datasets retain their data channels. Channel labels without coordinates trigger a lookup prompt using a packaged montage. Channel-edit history uses replayable MATLAB cell arguments (Stream 5, #550; F36, F49).

  • Standard montage lookup applies the EEGLAB nose-axis rotation for standard_1005.elc and recognizes BESA .elp files. Reading polar .locs files uses an 85 mm head radius and preserves labels after repeated tabs. A lookup with no matching labels preserves existing coordinates (#550; F45, F46).

  • pop_reref reference, exclusion, and related channel numbers, and eeg_interp channel numbers, are now 1-based in scripts and GUI fields, matching pop_interp. Existing scripts using NumPy row indices must add 1 at these API boundaries; array indexing and low-level reref remain zero-based. GUI entry 2 6 excludes channels 2 and 6 and records those numbers in history. Console replay, CLI rereferencing, and spectral rejection use the same convention. Empty reference state displays as unknown (#550, #569; F12, F61, F62, F70).

  • Channel-coordinate edits reject nonnumeric or nonfinite values with a field name and correction instructions. This deliberately differs from the audited EEGLAB behavior that accepted theta='abc'; a regression test locks the validation (#550; F43).

  • Event selection records numeric criteria for numeric event codes and preserves string codes as text. Data selection preserves input precision; embedded save precision remains with the S1 stream (F50, #548).

  • Cropping epoched data recalculates event latencies per epoch and preserves cached ICA alignment. The tutorial selection retains 129 inclusive samples and 8 events; the documented EEGLAB endpoint difference remains intentional (F44, #548).

  • Select events warns when no events match and explains how to adjust the selection, including when boundary events are retained (F40, #548).

  • About this dataset preserves comment line breaks, including blank lines, in the editor and saved comments (F48, #548).

  • Extract epochs supports selecting several event types together in its picker (F124, #548).

  • Parks–McClellan Estimate opens the ripple/attenuation sub-dialog and leaves the filter settings unchanged on Cancel (F101, #548).

  • Event fields displays readable descriptions, supports editing them, and opens file pickers for existing and new fields, including paths with spaces (F100, #548).

  • Data and ICA rejection menus fit within 1073×994 pixels and enable calculation, plotting, Help, and color controls. Calculated marks and history are retained when closing the menu. Probability and kurtosis PLOT open the scrolling rejection browser with calculated marks (F102/F105, #548).

  • Select epochs or events opens tutorial datasets with MATLAB array descriptions and displays each readable description beside its corresponding field (F39, #548).

  • Select data opens tutorial datasets whose channel types are empty MATLAB arrays. The channel-type picker is disabled when all types are absent or blank (release-readiness F37, #548).

  • The Select data dialog validates channel numbers before conversion to Python indices. Range errors preserve the entered numbers and give the valid one-based range.

  • The fuzz harness accepts platform-specific baseline-mean summation roundoff for pop_rmbase (#542) within four float64 eps times the largest finite output magnitude (floored at one). Larger gaps and other mismatch types remain findings. Baseline processing and stored tolerances are unchanged.

  • The fuzz adapter converts EEGLAB’s 1-based channel indices to Python pop_select’s 0-based indices (#543). Duplicate-channel draws use the cropped channel count. Python out-of-range errors name pop_select, the invalid indices, nbchan, and the valid Python and EEGLAB/GUI ranges.

  • Replaying a folder import records [STUDY, ALLEEG] = pop_importbids(...) with return_study on, so the console rebuilds the same study. pop_importbids.m always returns STUDY and ALLEEG. The direct call still returns the datasets unless return_study=True. The history also keeps the dialog’s recordings selection, along with task, session, run, and subject.

  • pop_importbids(..., subjects=[1, 2]) uses the same 1-based participant indices as the import dialog (pop_importbids.m lines 163 and 281). Replaying the recorded 'subjects', [1 2] command selects those participants. An index outside that list raises pop_importbids and names the valid range.

  • pop_exportbids writes each study dataset under its own subject. The label comes from EEG.subject, then the matching STUDY.datasetinfo subject (pop_exportbids.m lines 167-172). A dataset with neither set raises pop_exportbids: no subject info found.... One dataset with no subject still uses the subject argument. createids assigns sub-001, sub-002, and so on to the unique subjects (bids_export.m lines 605-608), so two sessions of one subject keep one id and participants.tsv has one row per subject. Session and run are taken from the dataset when they are set. The export dialog records a command that replays in eegprep-console with the dataset list, task, license, changes, and createids. EEGLAB leaves this command empty (pop_exportbids.m lines 247-252).

  • The BIDS import field “Import only the following participant indices” takes 1-based indices into participants.tsv order, or sorted sub-* folder names when that file is missing (pop_importbids.m lines 163 and 281). The indices are mapped to subject labels before the file filter. A non-numeric or out-of-range value raises pop_importbids. The history command records the numbers, for example 'subjects', [1 2].

  • pop_rejspec multitaper estimation stops each series on its own pmtm test, sum(abs(S-S1))/nfft > tol. A non-finite change stops that series, so one NaN sample returns instead of looping. Finite tutorial epochs are unchanged: ±30 dB and ±35 dB still mark nothing.

  • Reject marked epochs records eeg_rejsuperpose only after the new-dataset dialog is accepted. Cancelling that dialog leaves the command history as it was.

  • vararg2str continuous-array history uses MATLAB num2str (vararg2str.m:196-242).

  • pop_rejspec multitaper power is 10*log10 (dB). pop_rejspec.m:310 uses 10*log (natural log). On eeglab_data_epochs_ica.set, 15–30 Hz at ±35 dB marks no data epochs; EEGLAB marks epoch 37. At ±30 dB, EEGPrep marks no data epochs and no component epochs; EEGLAB marks data epoch 37 and components 13, 14, 15, 26, and 79.

  • pop_rejcont applies frequency limits to the real FFT bin frequencies. pop_rejcont.m:211 stretches those bins with linspace from 0 to Nyquist. On eeglab_data.set, 20–40 Hz at 10 dB keeps 27720 points in 8 regions; EEGLAB keeps 28008 points in 9.

  • pop_rejcont accepts a [min max] threshold and a cell of thresholds or frequency ranges (pop_rejcont.m:172-177 and pop_rejcont.m:239). A single limit is still expanded to [-100 limit]. On eeglab_data.set, [-50 10] keeps 27720 points in 8 regions and [-5 10] keeps 3432 points in 17 regions.

  • pop_rejcont history leaves eegplot out of the commented call (pop_rejcont.m:370). Accepting the marked regions records a separate pop_select( EEG, 'nopoint',[...]); entry (pop_select.m:749).

  • A two-number threshold typed into the pop_rejcont dialog, such as -50 10, stays [min max]. pop_rejcont.m:147 reads that field with str2double, which becomes NaN and rejects nothing. On eeglab_data.set, -50 10 still keeps 27720 points in 8 regions.

  • pop_rejcont with correct blank writes the zeroed samples back onto the dataset. A float32 recording is copied by the floating-point conversion, so the zeros have to be stored explicitly. On eeglab_data.set, 20-40 Hz at 10 dB with the default taper zeroes 1312 columns.

  • pop_eegthresh history uses the vararg2str form at pop_eegthresh.m:251-252, with contiguous ranges collapsed. The reject flag is the value that was applied. pop_eegthresh.m:252 always writes 0, so replaying a scripted reject=1 call in EEGLAB only marks the epochs. Dialog times use MATLAB num2str: five significant digits below 1, and floor(log10(|x|))+5 digits otherwise. The sample epoch file shows an end time of 1.9922; 12.34567 is 12.3457 and 123.456789 is 123.4568.

  • Update Marks shows the warning that epochs marked for rejection have been noted (eeg_rejmacro.m:119-121).

  • pop_rejcont reports the Add trails field, the function name, and an example value when that field is not one number of seconds.

  • The reject-by-spectra dialog opens on FFT (pop_rejspec.m:142-149).

  • pop_autorej reports which dialog field was not numeric, and shows a valid example, instead of a bare float conversion error.

  • Export marks to ICA reject now superposes data marks and copies rejglobal onto icarejmanual (eeglab.m:661-662). Export marks to data reject copies ICA marks onto rejmanual (eeglab.m:674-675).

  • pop_rejchan now rejects probability and kurtosis channels with the two-sided mask from rejkurt.m:131 and jointprob.m:133, after the 10% trimmed normalization at rejkurt.m:109-114. The dialog offers Probability, Kurtosis, and Spectrum (pop_rejchan.m:96) and enables the frequency range only for Spectrum (pop_rejchan.m:99-100). History uses the vararg2str form at pop_rejchan.m:246.

  • pop_rejspec multitaper spectra follow pop_rejspec.m:307-326 for the seven adaptive Slepian tapers and the eegthresh bin limits, and convert power with 10*log10 rather than the natural log at pop_rejspec.m:310. On eeglab_data_epochs_ica.set that marks no epochs at ±30 dB or ±35 dB.

On eeglab_data.set the 20-40 Hz, 10 dB settings remove 8 regions and keep 27720 points. The scroll view uses the eegplot.m:457-473 spacing, and the dialog has no Help button (pop_rejcont.m:140).

  • Channel-mode automatic epoch rejection uses rejkurt. pop_autorej.m:224 uses icarejkurt, so on eeglab_data_epochs_ica.set EEGLAB keeps 75 epochs and EEGPrep keeps 74.

  • Clicking or dragging in the scroll window marks data again. The plot viewport was asked for mapToScene, which only QGraphicsView provides, so every left click raised AttributeError. Continuous drags mark the 1-based sample range round(x * srate) + 1 (eegplot.m lines 2110-2144). An epoched click marks or clears that whole epoch on mouse-down, including a one-sample epoch, and a drag does not spread to other epochs (eegplot.m lines 2130-2135). Channel inspection, epoch inspection, and ICA component inspection share this path.

  • Rejecting marked continuous data records EEG = eeg_eegrej( EEG, ...); from the reduced two-column regions (eeg_eegrej.m builds that command after combineregions) and asks what to do with the new dataset through pop_newset. Cancel keeps the original dataset and does not record the rejection. An empty mark does nothing (eeg_eegrej.m lines 59-60).

  • Tools > Inspect/reject data by eye shows the instruction dialog from pop_eegplot.m lines 180-186 before the browser opens. That menu calls pop_eegplot(EEG, 1) (eeglab.m line 644). Cancel returns without opening the browser. Closing the dialog also stays on the current dataset; EEGLAB continues unless the button text is Cancel. Plot > Channel data (scroll) passes reject explicitly (eeglab.m line 683) and does not show the dialog.

  • Rejecting marked epochs asks “Are you sure, you want to reject the labeled trials ?” (pop_rejepoch.m lines 78-84) only when Reject is removing epochs. Update Marks does not ask. NO, or closing the dialog, leaves the epochs in place. YES removes them and opens pop_newset. Clearing every mark and pressing Reject stores the manual marks as unmarked and does not add a rejection command. The history command uses pop_rejepoch( EEG, [..] ,0); (pop_rejepoch.m line 101).

  • File > Export opens the pop_export, pop_writeeeg, and pop_exportbids dialogs (pop_export.m lines 77-115, pop_writeeeg.m lines 52-80, pop_exportbids.m lines 48-83). pop_expica and pop_expevents stay file pickers, matching pop_expica.m lines 61-69 and pop_expevents.m lines 67-73.

  • Importing a BIDS dataset replaces a missing chaninfo.plotrad or chaninfo.shrink with an empty array, so File > Save no longer fails while savemat is writing those fields. The import dialog matches pop_importbids.m lines 104-164 and loads an in-memory study. It does not copy datasets into derivatives/eeglab (pop_importbids.m lines 839 and 892 do).

  • pop_writeeeg keeps every EDF and BDF sample and every event annotation. EEGLAB writeeeg.m line 139 shortens a block longer than 1000 samples to one second (round(srate) samples per record). Biosig then pads the file to that record boundary and fills the extra samples with the digital minimum, which reads back as the channel physical minimum. A 2112-sample recording at 200 Hz is 11 seconds from EEGLAB and stays 2112 samples in EEGPrep. pop_writeeeg.m line 97 records the command without a LASTCOM prefix. Epoched data is concatenated after the same confirmation as lines 53-57.

  • pop_exportbids writes README, *_eeg.json, *_electrodes.tsv, and *_coordsystem.json. The electrodes and coordinate-system names drop task- and desc- (bids_writeelectrodefile.m lines 32-49 and 272-316). It runs the official bids-validator when bids-validator, npx, or deno is on PATH, and otherwise says the check was sidecars only and how to install the validator. It does not add eegprep_bids_validation.json to the dataset. The File menu exports a study only (pop_exportbids.m line 33). pop_exportbids(EEG, folder) still writes one dataset from memory.

  • BIDS import uses the value column as the EEG event type when that column exists (bids_importeventfile.m line 14, pop_importbids.m line 181). trial_type is still used when value is absent. A nan event type is stored as an empty string. The import dialog’s task, session, run, and recording selectors are the popup and listboxes from pop_importbids.m lines 112-118, filled by scanning the folder. Empty session, run, and recording rows are omitted (lines 128-142).

  • The export dialog’s “Number of significant digits” field is passed through as %.Nf decimal places, which is what pop_export.m line 179 does with the string from line 93. The function default remains 7 decimal places (line 129). The dialog default remains 4 (line 94) and is the edit field’s value, so pressing Ok without changing that field writes 4 decimal places.

  • newtimef and timefreq keep every requested output time, including times that round onto the same sample. timefreq.m gettimes drops duplicates only when the index list is shorter than its unique values, so that drop never runs. A 128-sample epoch from -500 ms to 492 ms at 128 Hz, cycles [3, 0.8], and padratio 1 returns 111 times.

  • timefreq spaces that time grid the way MATLAB linspace does: start + i * (stop - start) / (n - 1), and the last point is the end limit. Spacing the step first moved 26 of those 111 times by one unit in the last place, and five of them (including one in the baseline) crossed a half-sample, so every ERSP row picked up a constant dB offset.

  • plotfresp accepts the symmetric and antisymmetric FIR filters that fir_filterdcpadded already runs. plotfresp.m line 67 compares coefficients with exact reversal, so a windowed-sinc highpass whose taps are linear-phase but not bit-identical raised “Onepass-zerophase filtering is only allowed for linear-phase FIR filters” and the default frequency- response plot never opened.

  • eeg_interp limits a time range with inclusive EEG.times in milliseconds, on continuous and epoched data. A full-range list equal to [xmin, xmax] no longer restores the second-to-last sample. Pinned eeg_interp.m line 322 restores floor(t*srate) and stops short of the last sample; this follows the inclusive window in eeglab pull 980.

  • pop_interp keeps a scripted t_range. Pinned pop_interp.m line 61 sets t_range = '' and interpolates the whole recording; the help text and a regression test record that difference.

  • pop_interp channel indices are 1-based. Channel 1 is the first channel. Replayed history keeps those indices.

  • runica extended kurtosis draws fix(rand*datalength) on the RandomState(5489) stream and divides by m2 (runica.m lines 890-903). With posact off, component order uses sphered-channel energy (runica.m lines 1472 and 1519).

  • newcrossf defaults the frequency range to [0, 50] Hz (newcrossf.m lines 396-397). A log scale still lifts a zero lower edge to 3 Hz (line 461). The previous default followed timefreq up to Nyquist, so a 128 Hz epoch with padratio 1 ran 6-64 Hz instead of 6-50 Hz.

  • The cross-coherence and time-frequency dialogs show epoch limits with MATLAB int2str rounding, halves away from zero (pop_newcrossf.m line 87, pop_newtimef.m line 172), so 0.9996 s is 1000 ms. When the frequency field is empty and the epoch starts before zero, pop_newtimef sets winsize the same way (pop_newtimef.m line 292): xmin -0.1 s at 256 Hz is 26 samples.

  • Sample indices that follow MATLAB round send halves away from zero. [25 800] ms at 100 Hz with xmin 0 starts at sample 3 (pop_newtimef.m lines 305-306; pop_newcrossf.m line 188 uses the same round). The same tie is used for time-warp frames (newtimef.m lines 630 and 635), the envtopo contribution window (lines 418-419), dftfilt tapers (lines 70-71), spectopo percent and window length (lines 320 and 895), scroll-window bounds and click latencies (eegplot.m lines 1318-1319, 1403, and 2028-2029), rejection regions (eegrej.m line 82), the kurtosis and joint-probability trim (rejkurt.m line 110, jointprob.m line 115), scalp-map and epoch dialogs (pop_topoplot.m lines 104 and 391, pop_headplot.m line 159, pop_epoch.m line 122), and epoch latencies (eeg_checkset.m line 652).

  • pop_newtimef takes the EEGLAB sample window (pop_newtimef.m lines 305-306) and passes those requested time limits into the decomposition. pop_newcrossf uses that same inclusive end. Pinned pop_newcrossf.m line 189 omits the +1, so EEGLAB drops the last sample of a whole-millisecond limit; the help text and a regression test record that difference. The previous slice dropped the sample after that limit and evaluated the decomposition on the kept sample times, so an explicit baseline did not move the result.

  • pop_fileio_brainvision_mat channel locations include empty ref and type on every channel. MATLAB eeg_checkset fills a missing chanlocs.ref with '' (eeg_checkset.m lines 1105-1117) and the checked structure also carries empty type. An unknown channel variable is still appended once.

  • pop_fileio_brainvision_mat reads a BrainVision Analyzer MATLAB export the way bva-io pop_loadbva.m lines 46-139 does: one variable per channel, SampleRate, the t axis in milliseconds, and Markers. Channel locations are converted with convertlocs(..., 'sphbesa2all') and the BESA angles are then removed (lines 101-103), leaving theta, radius, X/Y/Z, and spherical coordinates. A marker with an empty Description is skipped (lines 112-113). A name such as xFp1 matches channel Fp1. An unknown channel variable is appended once. pop_loadbva.m lines 61-65 each call chanstruct(end+1), so EEGLAB appends four records (one named record and three empty ones). A MATLAB v7.3 file or any other .mat layout raises an error instead of returning a one-channel guess. The history command remains pop_fileio_brainvision_mat. The dataset filename is left empty so a later resave cannot overwrite the .mat export.

  • File > Clear dataset(s) and Edit > Delete dataset(s) from memory ask for confirmation in the same dialog as EEGLAB pop_delset.m lines 56-70 (“Delete dataset – pop_delset()”, “Dataset(s) to delete:”). Cancel deletes nothing. With only one dataset loaded, the menu refuses and points at File > Clear study / Clear all. EEGLAB raises “Restart EEGLAB” for that case (pop_delset.m lines 52-54) and also blocks a direct call. pop_delset(ALLEEG, index) still deletes the last dataset. A dataset number that is not loaded raises ValueError from pop_delset (previously IndexError). EEGLAB reports that case as Error: no such dataset.

  • pop_saveset checks that the .set file exists before it marks the dataset saved. If the parent folder cannot be created or the file is not written, it raises an error that names pop_saveset and the path. Creating a missing parent folder was already the behavior.

  • Edit > Event values and Edit > Channel locations treat the number field as a goto. Enter shows that event or channel, and a number outside the list is clamped to the ends, as in pop_editeventvals.m lines 153-160 and 571. An edit is applied to the record on screen before the arrows or a typed number leave it, and Ok records every edit. EEGLAB writes each field from its edit callback before navigation. A number that is still out of range raises an error from pop_editeventvals or pop_chanedit instead of list index out of range.

  • pop_saveset resave writes only an existing .set file. File > Resave on a dataset imported from .vhdr, .edf, or another raw file opens Save as instead of replacing that recording. Any filename extension is replaced with .set (pop_saveset.m lines 126-127). File > Save current dataset as asks before replacing that .set file.   • Current EEGLAB visual-wrapper test ports now exercise plots through deterministic headless numerical and figure assertions. pop_plotdata supports channel/component mode, 1-based trial selection, trial averaging, and single-trial overlays; pop_plottopo honors its positional title and single-trial arguments. pop_spectopo supports Blackman-Harris windows and blckhn, and pop_envtopo accepts the legacy compnums=-N top-N shorthand. pop_topoplot renders signed EEG.chanmatrix grids even when channel locations are unavailable.

  • The current EEGLAB GUI-helper tests now have deterministic Python ports. supergui builds declarative dialogs without entering a modal loop, inputgui supports a non-blocking mode="plot" workflow and renders radio buttons, and listdlg2 accepts multi-line prompts and custom OK and Cancel labels.

  • Core event and channel helpers now cover EEGLAB-compatible event insertion, event histograms and type counts, per-epoch field extraction, boundary-aware original latencies and context queries, channel-type lookup and montage matching/merging, ERP-window amplitude, and bad-time interpolation. These helpers are available directly from eegprep and run without an EEGLAB checkout.

  • pop_loadset now supports EEGLAB’s metadata-only and 1-based channel loading modes, while pop_fileio applies 1-based channel and inclusive sample/trial selections with consistent dataset bookkeeping. pop_writeeeg now writes real EDF and BDF files through the installed writer instead of routing unsupported BDF format names into MNE’s EDF-only exporter.

  • Added pop_dipparams, pop_erpimparams, pop_erpparams, pop_erspparams, pop_specparams, and pop_statparams for storing EEGLAB-compatible STUDY plotting and statistics settings. Analysis-defining range changes now invalidate stale measure caches. std_maketrialinfo now derives custom fields such as reaction time from each epoch’s time-locking event and preserves those rows across later STUDY operations. Saving .set files now supports event dictionaries with heterogeneous custom fields by encoding absent struct values as MATLAB empty arrays.

  • pop_clean_rawdata now routes channel cleaning to the location-free algorithm when EEG["chanlocs"] is empty. It previously failed with an indexing error before the documented fallback could run.

  • Current EEGLAB rejection-workflow test ports now cover threshold, statistical, spectral, trend, channel, epoch, and automatic rejection. Scripted pop_rejchan calls use EEGLAB’s default threshold of 400; the interactive dialog continues to default to a normalized threshold of 5.

  • Topographic interpolation no longer leaks NumPy 2 floating-point warnings for finite biharmonic matrix products.

  • eeg_interp now accepts MATLAB-loaded object arrays of channel locations when restoring a full montage. pop_editeventfield now reads values from delimited text files, accepts MATLAB colon expressions for event indices, rebuilds urevent after delold='yes', and ignores invalid rename/description requests like EEGLAB.

  • pop_reref now accepts EEGLAB’s method='standard' option explicitly. Other rereferencing methods fail clearly instead of being silently treated as standard, and NumPy 2’s spurious finite-matrix warnings no longer leak from average reference.

  • pop_selectevent now supports erroronempty='off' when a selection removes every epoch, returning an empty EEG instead of raising. Component pop_topoplot colorbars now use polarity labels only for scales that span zero; positive-only and negative-only scales show their exact numeric maplimits endpoints. eeg_decodechan now accepts EEGLAB’s whitespace-separated channel-name form as well as Python sequences. ICA rejection marks can also derive their row count from icachansind when stored ICA matrices are absent.

  • Current EEGLAB admin/GUI test ports exposed and fixed three parity defects: eeg_retrieve(ALLEEG, 0) now returns the empty no-current dataset, multi-dataset commands receive EEGLAB’s marker in each dataset history, and listdlg2 treats a scalar string as one selectable item while preserving its 1-based initial selection.

  • Compatibility helpers now cover EEGLAB key/value validation, option-file and help-header parsing, history-value extraction and formatting, and the generic inputdlg2 and errordlg2 dialogs without runtime access to EEGLAB.

  • pop_autorej (Tools > Automatic epoch rejection) now runs EEGLAB’s probability loop exactly: a pass rejects its flagged epochs only when they are fewer than maxrej percent of the remaining epochs (5% of 80 epochs is not fewer, so the threshold is raised instead), and once a pass flags nothing the threshold walks back down in 0.5 s.d. steps toward 5 s.d. for up to eight pruning rounds instead of stopping at the first clean pass. The final kurtosis pass is applied in channel mode as well; EEGLAB currently skips it there because it reads the component rejection field. Rejected epochs on the epoched sample dataset now match tests/matlab/pop_autorej_reference.m.

  • Deleting a dataset that belongs to a STUDY no longer shifts its STUDY metadata (subject, condition, group, session, run, and components) onto the following datasets. The deleted dataset’s datasetinfo row is dropped together with its ALLEEG slot, as EEGLAB’s std_editset does, so std_checkset and the STUDY editor keep each dataset’s metadata with that dataset.

  • newtimef / pop_newtimef now return the baseline power spectrum (powbase) in dB for the default log power scale with a baseline, matching EEGLAB’s mbase; it was previously returned in absolute power. It stays in absolute power for absolute-scale, basenorm, and trialbase runs and when no baseline is used (as in EEGLAB), and the plotted figure is unchanged. std_precomp correspondingly caches the STUDY erspbase field in dB for its default log/baseline settings; rerun precomputation with recompute='on' to refresh values cached by an earlier version.

  • pop_newtimef / newtimef now render EEGLAB’s single-condition ERSP/ITC time-frequency figure. The ERSP and ITC images use a symmetric color axis, a stimulus-onset (time 0) marker, right-hand colorbars titled with the power unit, and the turbo colormap (EEGPrep’s house colormap, consistent with topoplot and erpimage); ITC is colored by its phase sign by default (plotphasesign), with plotphaseonly showing the phase angle in degrees. The figure adds EEGLAB’s marginal panels – the ERSP min/max envelope and ERP trace below the images, and the rotated baseline power spectrum and mean ITC to their left – using EEGLAB’s value-axis limits and two ticks per panel. When channel locations are available it also draws the channel or component scalp-map inset and caption (the channel label or IC n), marking the selected electrode for channels. The erspmax / itcmax dialog fields set the ERSP and ITC color limits, and the default frequency range stops at 50 Hz (EEGLAB’s maxfreq, capped at Nyquist).

  • pop_newtimef / newtimef bootstrap significance now matches EEGLAB. With a significance level (alpha), each time-frequency point is ranked against a per-frequency baseline null built by permuting the baseline time course (EEGLAB’s shuffle permutation, averaged over trials), and the p-value folds to a two-sided tail (EEGLAB’s compute_pvals) for both ERSP and ITC – so the scattered baseline false positives EEGLAB shows are reproduced and genuine event-related effects survive masking. Non-significant regions are shown as the colormap midpoint, or outlined with contours instead when pcontour is set; the FDR (mcorrect) path is supported. A non-default boottype ('rand' / 'randall') is now rejected with a clear error rather than silently treated as 'shuffle'.

  • timefreq – and the newtimef / pop_newtimef plots built on it – now match EEGLAB’s decomposition numerics. Requested output frequencies are no longer de-duplicated, so freqs/nfreqs requests that snap several values onto the same FFT bin return one output frequency per request (as in EEGLAB) – this changes the pac output shape (for example (5, 3, 8) becomes (5, 5, 8)); detrend is now a no-op on the FFT (cycles=0) path; output time windows are centered with EEGLAB’s eeg_lat2point rounding and the negative-ntimesout subsample grid no longer includes a spurious trailing time point; subitc returns the pre-subtraction inter-trial coherence; and exact-zero spectral bins are guarded as in EEGLAB. Some outputs change shape or value versus earlier EEGPrep releases.

  • Deleting datasets (pop_delset, Edit > Delete dataset(s) from memory) now empties the slot in place like EEGLAB instead of shifting later datasets down, so dataset numbers in the Datasets menu, CURRENTSET, and the history stay valid. eeg_store stores new datasets in the lowest empty slot, trailing empty slots are dropped, and pop_delset raises for a dataset number that does not exist. A dataset selection can no longer land on an emptied slot; it falls back to a remaining dataset the way EEGLAB’s redraw does. Creating or editing a STUDY still compacts the empty slots away, because a STUDY needs contiguous dataset numbers, but the selection now follows the dataset it was on instead of its old number. Editing a STUDY design, precomputing measures, and preclustering no longer modify ALLEEG, matching EEGLAB’s e_plot_study.

  • pop_prop (Plot > Channel/Component properties) now matches EEGLAB’s three-panel layout: a scalp map, an ERP image, and the activity power spectrum. The ERP panel is a full ERP image (reusing erpimage) instead of a single averaged trace, the spectrum is computed from the raw per-epoch data, and component spectra are scaled by the component map power (mapnorm) so their levels match EEGLAB. Channel maps mark the selected channel’s location, and the spectrum y-axis stays tight to the plotted frequency band instead of stretching to out-of-view frequencies. The ERP average panel is labeled “ERP” for channels and left blank for components, since ICA component activations are unitless, matching EEGLAB. The ERP trace now sits flush beneath the ERP image (only the trace carries the time axis), and the “pop_prop() - <name> properties” label is shown in the window title bar rather than on the canvas, as EEGLAB does.

  • Scalp maps now render with EEGLAB’s left-right orientation. topoplot, plottopo, and erpimage previously mirrored electrode markers, labels, and interpolated data along the left-right axis; channel positions now match EEGLAB (F4 on the right, F3 on the left). Dataset contents and history are unaffected.

Version 0.3.0#

Released 2026-08-11

  • clean_rawdata now processes data at any sampling rate. ASR calibration previously relied on a table of pre-computed spectral-shaping filter coefficients covering only 100, 128, 200, 250, 256, 300, 500 and 512 Hz, and raised an error otherwise, so common clinical rates such as 258 Hz could not be cleaned without resampling first. The filter is now designed for the recording’s own rate with a yulewalk port, matching what EEGLAB’s asr_calibrate.m does. See Preprocessing Pipeline.

  • eegprep.rmbase now exposes the low-level EEGLAB-style numeric baseline helper; use pop_rmbase for EEG dataset dictionaries.
