# EEG_HELPMISC - Miscellaneous command-line functions

Miscellaneous EEGPrep helpers cover conversion, numerical utility, and
development support functions that are not direct main-window workflows.

Use the API reference for exact signatures. The most common user-facing paths
are still the `pop_*` wrappers, plugin wrappers, and `eegprep-console`
workspace commands documented elsewhere in packaged help.

Runtime package code should not read the vendored EEGLAB reference tree for
miscellaneous help or examples.

See also: EEG_HELPPOP, EEG_HELPADMIN
