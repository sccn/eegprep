# POP_STUDYERP - Create a simple ERP STUDY

`pop_studyerp` creates a STUDY marked with a simple ERP design.

Usage:

```python
STUDY, ALLEEG, com = pop_studyerp(ALLEEG)
```

Use this helper when loaded epoched datasets should be grouped for ERP-style
channel plotting. More complete STUDY design management is Phase 5 work.

See also: POP_STUDY, POP_CHANPLOT
