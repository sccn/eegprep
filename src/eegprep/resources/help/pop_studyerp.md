# Create a simple ERP STUDY

`pop_studyerp` asks how many conditions and subjects to include, then shows one dataset box per subject and condition. Fill at least one box and press Ok to build the STUDY. Cancel on either dialog leaves the workspace unchanged.

Datasets on one line belong to the same subject. Subject codes are filled in as `S01`, `S02`, and so on so the STUDY can be created without typing them first.
