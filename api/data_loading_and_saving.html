BrainVision recordings#

Load a BrainVision Data Exchange recording through its header. The companion data and marker files are resolved from the header and must remain beside it.

from eegprep import pop_loadbv

EEG = pop_loadbv("subject01.vhdr")
EEG = pop_loadbv("/data/session", "subject01.vhdr", [1001, 5000], [1, 2, 8])

srange and chans use EEGLAB-compatible 1-based indexing; a two-value sample range is inclusive. Binary and ASCII, multiplexed and vectorized data are supported. Voltage data is normalized to microvolts while the original unit and resolution remain in each channel’s bvunit and bvresolution fields. Use metadata=True to inspect dimensions, channels, and events without loading samples. Uniform marker-based or fixed-time segments are returned as trials rather than a flattened continuous array.

read_erpss reads uncompressed and delta-compressed ERPSS .RAW and .RDF recordings without a compiled MEX extension. It preserves channel labels and 1-based event sample offsets, and supports both little- and big-endian files.

readegi reads EGI Simple Binary RAW versions 2 through 7 without an EEGLAB installation. Frame and segment selections are 1-based, while returned sample arrays are channel-major. readegihdr reads the same acquisition and event-code metadata without loading signal samples.
